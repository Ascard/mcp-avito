## 🐛 Известные проблемы

### Критические
- Нет критических проблем

### Некритические
- **Датацентр прокси блокируются Avito** - Решение: использовать резидентные прокси
- **Location не парсится** - Некоторые элементы не имеют локации в списке результатов
- **Pagination может зациклиться** - Если Avito вернет пустую страницу, но с валидным HTML
